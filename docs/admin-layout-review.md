- 全站/负责城市的权限仍服务端决定；受保护值仍不下发；本城普通空值继承，空频道标签隐藏。

- 未保存离开提醒、保存失败留草稿、保存中防切换、并发请求票据不变。
- 频道仍正文文字链接；私聊按钮仍使用既有渲染/校验；重试不重做成功步骤，unknown无盲目重发。
- 没有迁框架、新增业务功能、迁移数据库、改生产配置、上线或发送真实Telegram。
- 只对修改的 `workspace.css / workspace.js / admin-buttons.js` 使用 `20261111b`；未改变访客bundle及其版本。
