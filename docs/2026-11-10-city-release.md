# 月影车姬 · 城市社区 / 桌面设置 / 通知按钮

本批以 PR #53（ef55127）为基线；不包含未合并热修分支，不做钱包、会员、预约金。

## 同批交付
- 站点设置六分组：本城社区、频道帖文案、首页展示、规则与通知、老师「我的上架」数据、系统。桌面暗色主题，前两组默认展开；明确保存全站 / 本城市，城市公告同范围保存。运营负责城市与原有运营名单保留于系统。
- 官方讨论群、防失联、本城位置 URL / 文案：可按城覆盖；空 URL 继承全站、关闭「本城社区外链」显式隐藏外链。未配置不生成入口。位置频道文字链可选开启，空文字隐藏，与 URL 的继承语义分开。
- 审核通过私信默认附资料深链及「查看我的资料」Mini App 按钮；有相册才附「查看频道帖」。原频道相册、机器人文字链接保留，可按城关闭新增按钮。
- 全站欢迎语按钮编辑器：最多6个、每行2个，仅支持首页 / 我的 Mini App 或合法 HTTPS URL。运行时丢弃无效配置；无按钮继续移除旧键盘。只在私聊使用 Web App 消息按钮，管理员后台独立消息与常驻「首页」菜单不变。
- 城市社区汇总现有频道、已刷新的按区目录、精选评价、优惠频道及新增外链；「我的」与首页可进入，不新增底栏。
- 首页列表 / 地图共享原搜索、地区、排序及全部筛选条件。地图只发送公开行政区中心聚合，绝不发送资料或用户坐标；未知地区保留列表，底图失败保留结果。最多扫描600份，达上限显示缩小筛选说明。首页列表页大小、117×224三列卡片不改。
- 轻量评价榜：近30天人工审核通过评价，每用户每资料一次；仅本城在架资料，零样本不编榜，计数并列同名次，稳定 ID 顺序作展示排序。
- 详情信任层：资料审核提示和评价数只在详情显示。评价仅真实人工审核有「已审核」；真实 proof_count>0 才显示「已提交凭证」，不公开私密凭证，不冒充凭证核验。休息中显示「暂不联系」并在服务端拒绝新会话。

## 保留 / 不做
- 地铁没有站点数据集或专用站点召回；现有 approx_label 普通文本搜索不是地铁搜索。本批不更换占位词、不伪称支持地铁。
- 频道保持文字链，无内联按钮。目录配置仍等北京时间12:00刷新；社区展示最后成功刷新的目录引用。
- 超管字段权限、空城市字段继承、空频道文字隐藏、历史频道帖文案同步保持。
- 资源版本：仅变更的 Mini App bundles 与管理资源更新为 `20261110b`；HTML 不缓存；MenuButton 仍打开 go.html，继续从该页读取 bundle 版本。
